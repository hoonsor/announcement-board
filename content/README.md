# 內容編輯說明（給服務組使用）

這個資料夾裡的 `.md` 檔案，就是網站上會顯示的文字內容。您可以直接編輯這些檔案來修改網站文字、按鈕、檢核清單項目、清運點資訊等，**不需要碰任何程式碼**。

## 怎麼修改

1. 用文字編輯器（記事本、Word、VS Code 都可以）打開對應的 `.md` 檔案
2. 直接修改冒號 `：` 後面的文字，或增刪 `- ` 開頭的條列項目
3. 存檔後，告訴 Claude：「我改好 content 裡的 XXX.md 了，幫我同步到網站」
4. Claude 會執行同步、重新建置並確認網站畫面正確，再回報給您

如果您自己有安裝 Node.js，也可以自行執行以下指令完成同步（不需要 Claude 協助）：

```bash
npm run sync-content   # 把 content/ 底下的 .md 內容轉換成網站程式讀取的資料檔
npm run build          # 確認網站可以正常建置（沒有錯誤代表格式正確）
```

## 檔案對照表

| 檔案 | 對應網站位置 |
| --- | --- |
| `content/site.md` | 網站標頭品牌文字、上方選單的標籤與說明、頁尾內容 |
| `content/home.md` | 首頁的大標題、按鈕文字、服務組工作內容卡片、活動期程重點 |
| `content/checklists/work-groups.md` | 「各工作組注意事項」頁面 |
| `content/checklists/competition-categories.md` | 「各競賽職種（校內）注意事項」頁面 |
| `content/checklists/co-organizers.md` | 「協辦單位注意事項」頁面 |
| `content/checklists/liaisons.md` | 「外派聯絡人注意事項」頁面 |
| `content/waste-collection-points.md` | 「競賽期間清運點」頁面文字說明，以及地圖上每個清運點的詳細資訊 |

## 編輯注意事項

- **請保留每行的中文標籤（例如「副標題：」「聯絡人：」），只修改冒號後面的內容**，這樣同步程式才能正確辨識。
- 檢核清單的條列項目，`- ` 開頭代表一個可勾選項目；您可以自由新增、刪除或修改文字，順序就是網站上顯示的順序。
- `content/waste-collection-points.md` 裡每個清運點的「代號」「位置座標」「標示顏色」是給地圖定位用的，**請盡量不要更動**；如果要新增清運點或調整地圖上的位置，建議直接請 Claude 協助處理，比較不容易出錯。
- 修改後記得存檔為「純文字 / UTF-8」格式（如果用記事本另存新檔，選擇編碼為 UTF-8）；用 VS Code 或一般純文字編輯器直接存檔則不需要特別設定。
